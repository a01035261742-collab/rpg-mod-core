# 밸런스 계산기 (대략)

- `python3 tools/balance/sim.py` : 직업·레벨별 사냥터 몹 몇 대에 잡나 / 몇 대 맞으면 죽나 / 레벨업 몇 마리 (기본 장비, 강화 없음)
- `python3 tools/balance/invest.py` : "평균보다 약간 아래" 강화·주문서·잠재·추가옵션 가정 시 딜 배율 (전사 기준)

0.50.0 몹 밸런스 기준:
- Lv10+ 몹 체력 × [Lv10 3.5, 15 3.3, 20 3.9, 25 3.9, 30 4.7, 35 4.8, 40 5.7, 45 5.8] (사이는 보간), 공격력 ×1.3 (Lv10~25) → ×1.5 (Lv30+). Lv1~9 그대로. 보스·기믹 몹 포함 (web_cocoon 제외)
- 배율 = invest.py 딜 배율 × 패시브 트리 (점수 레벨당 2, 점수당 딜 약 0.84%)
- 목표: 그 기준 캐릭터가 사냥터 몹 2방, 10대 맞으면 쓰러짐
- 계산은 단순화 (치명타·스킬 레벨·버프 대충). 실제 공식은 src/main/java/rpg/core/combat/Combat.java · CombatEvents.java
