## 5차. 스킬 (json vs 코드)

### 5-1. 스킬 포인트가 Lv1부터 한 통 — 중

- **지금:** Lv10에 27점 − 초보 스킬 10 = 17점 → 전직하자마자 1차 주력 Lv17.

| Lv | 전사 | 궁수 | 마법사 | 도적 |
|---|---|---|---|---|
| 10 | 2.9 → **1.9** | 3.5 → **2.2** | 3.7 → **2.3** | 3.6 → **2.3** |
| 11 | 1.6 → 1.1 | 1.9 → 1.3 | 2.1 → 1.4 | 2.0 → 1.4 |

| 15 | 0.8 → 0.7 | 0.9 → 0.8 | 1.0 → 0.8 | 1.0 → 0.8 |

  - 칸 = 현실 캐릭터 사냥 몇 방 (지난 계산 → 실제 스킬 레벨). 맨몸 Lv10은 6.9~8.2 → 4.6~5.2방.
- **왜:** 전직 전 9레벨 동안 쌓인 점수가 한 번에 들어감 → Lv11부터 1방.
- **추천:**

### 5-2. 클레릭 힐이 너무 셈 — 상
- **어디:** `skills.json` `heal` value 10→20 (대상 최대 HP %) + value2 50→100 (클레릭 스공 %), 쿨 4초, `MageSkills.heal` (8칸 파티 전원)
- **지금 (현실 캐릭터, 회복량 ÷ 대상 최대 HP):**

| | 힐 Lv1 | 힐 Lv20 |
|---|---|---|
| Lv30 (클레릭 스공 633) | 40~52% | 81~105% |
| Lv37 (스공 1,524) | 75~105% | 150~210% |

- **왜:** 스공 비례 부분이 너무 큼. 스공은 Lv30→45에 ×3.6인데 HP는 ×1.3~1.5. 클레릭이 있으면 한 방에 죽는 것 말고는 4초 안에 다 회복. 혼자서도 안 죽음.

  3. 쿨 4초 → **10초** (계수 그대로)

### 5-3. 지속 피해는 숙련·크리·방어율을 안 받음 — 중
- **어디:** `CombatEvents.fixedHit`·`dot` (독·화상·출혈·불길·빛의 사도·가시), `BranchSkills.poisonMist`
- **지금:**
  - 고정 피해 1% = 일반 타격 약 1.7% (수호자·여왕, 방어율 40~45). 크리가 높은 스나이퍼는 1.0~1.2.
  - 독안개는 9틱 (장판 6초 동안 0.5초마다 3초짜리 독을 다시 걸고, 끝나고 3초 더).
  - 트릭스터 여왕 혼자: 7.3분 → 6.5분 (트리 그대로) → 6.2분 (독안개를 엑스퍼트보다 먼저) → 5.2분 (지속 피해 노드 +95%·독 전문가 +30%, 약 21점). 어쌔신 3.0분.
- **왜:** 방어율 높은 보스일수록 독이 상대적으로 셈. 트릭스터가 약한 건 그대로(F2)지만 생각보다 덜 약함.
- **추천:**
  1. 그대로 (지속 피해 컨셉). F2 트릭스터 상향은 절반만 (분신술 600→1000 → 800→1250)
  2. 지속 피해에도 몹 방어율 적용
  3. 그대로 + 계산기에 반영 (H)

### 5-4. 지속 피해 덮어쓰기 — 하 (버그)
- **어디:** `CombatEvents.DOTS` 키 = "몹 id:종류" (주인 없음), `dot()`는 "같은 종류는 새로 덮어씀"
- **지금:**
  - 아크메이지 원소 공명(크리 때 화상 초당 10%)이 파이어볼 화상(초당 40%)을 덮음 → 원소 공명을 찍으면 화상 딜 손해.

- **추천:**
  1. 키에 주인 추가 (몹·종류·주인)
  2. 센 쪽 유지 (새 것이 약하면 시간만 늘림)
