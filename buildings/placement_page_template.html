NPC·몹 배치표

1번 맵과 2지역에 NPC, 퀘스트 지점, 사냥터(몹), 필드 보스, 마을 등록을 어디에 놓을지 정리한 표예요. 붙이기 기준점 좌표를 넣으면 순간이동 명령어가 실제 좌표로 바뀌어요. 지도의 번호와 목록 번호가 같아요.

기준점 = 1번 맵을 붙일 때 서 있던 자리 (분수 한가운데, 발 위치). F3 화면의 Block 좌표(정수)를 넣어요. 2지역도 같은 기준점에서 붙였으니 같은 값을 써요.

쓰는 법

  1. NPC: 첫 줄 순간이동(건물 쪽을 바라보게 됨) → 둘째 줄. NPC는 내 반대쪽, 즉 길 쪽을 보고 서요.
  2. 퀘스트 지점·보스·마을 등록: 순간이동 → 명령어. 서 있는 발밑이 그 자리가 돼요.
  3. 사냥터: /rpg wand 로 지팡이를 받고, 1번 모서리로 순간이동(아래를 보게 됨) → 발밑 블록 좌클릭, 2번 모서리로 순간이동 → 발밑 블록 우클릭 → 마지막 줄 명령어. 몹 종류·레벨은 번호마다 자동이에요.
  4. 다 놓은 뒤 /rpg quest check (빠진 NPC·지점 빨간색), /rpg zone show (사냥터 테두리)로 확인해요.
지도 누르면 크게 / 작게 NPC퀘스트 지점사냥터필드 보스마을 등록
